# 🧩 `SaleConfirmedDivider`

> Línea punteada (perforado de ticket) entre secciones del recibo de `SaleConfirmedModal`.

## 📦 Props

No recibe props. Toma su color de `theme.custom.saleTicket.divider`.

## 💡 Ejemplo

```tsx
<SaleConfirmedModalHeader onClose={onClose} />
<SaleConfirmedDivider />
<SaleConfirmedBrandStrip />
```
