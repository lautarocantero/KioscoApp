# 🧩 `CartCountBadge`

> Pill del header del carrito: cantidad de ítems o "vacío".

## 📦 Props

| Prop | Tipo | Descripción |
| --- | --- | --- |
| `itemsCount` | `number` | Cantidad de líneas en el carrito. |

## 💡 Ejemplo

```tsx
<CartCountBadge itemsCount={3} /> // "3 ítems"
<CartCountBadge itemsCount={0} /> // "vacío"
```
